# Unity Platformer — Code Documentation

This folder contains the documentation for the game's C# functions.

The purpose of this documentation is to explain how the code works internally, how Unity calls each function, and how the different scripts interact with each other.

The documentation focuses on the **behavior and interaction between functions**, rather than documenting every line of code.
